# Enable Classic Pattern Editor

WordPress plugin that adds a menu item to redirect to the classic post-list of patterns (`edit.php`) instead of the fancy new one (`site-editor.php`).

## Installation

Download the [latest release](https://github.com/BikeBearLabs/enable-classic-pattern-editor/releases/latest) of the plugin & install it on your WordPress site.

## Overview

This plugin adds a menu & a few submenus for patterns that emulates the editing experience of posts & pages. It is useful for those who prefer the classic editor over the new one, or for those who have pattern lists that take very long to load in the new editor.

## Usage

Open the `Patterns` menu on the left sidebar to manage your patterns. The submenus are the same as the ones in the classic post-list.
